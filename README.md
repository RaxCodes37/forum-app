Full-stack, fully functional Forum application.
Built using PostgreSQL and Drizzle on the back-end and Next.js, React, Typescript, and tailwind on the front-end.

## Usage

Creating an account with GitHub, Changing color message, sending message on global chat, creating a forum, and creating posts, comments, and replies.
